# vidbyte-memory

The vidbyte-memory extension is installed. It gives a repo correction-driven memory: each correction from the owner becomes a slim fact, a test and a footprint commit.

- In a repo that has `memory/MAP.md`, read that repo's `AGENTS.md` first and follow it on every request.
- In a repo without it, do nothing differently. When the owner asks to add memory to the repo, use the `install-memory` skill.
